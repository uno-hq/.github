## What is Uno?

Uno is a modern Discord bot built on **discord.js v14** and **Components V2**. It replaces a stack of single-purpose bots with one polished, reliable bot and a full web dashboard — no embed soup, no broken panels, no guesswork.

Every module is designed to be set up in seconds and managed from the browser:

- **Support tickets** — a static panel opens a private channel for the opener, every support role and the bot. Staff claim tickets, set priority, leave internal notes and use canned replies. Closing saves a self-contained HTML transcript to the log channel and the opener's DMs before the channel is deleted. Tickets can be reopened with the same number.
- **Music** — Lavalink-powered playback with queue control, filters, 24/7 mode and YouTube Music search by default.
- **AutoMod** — invite, link, caps, emoji-wall, repeat and mention filters, plus native Discord AutoMod rules kept in sync.
- **Leveling** — XP, ranks and leaderboards with role rewards.
- **Giveaways** — scheduled giveaways, requirements, rerolls and winner DMs.
- **Logging** — a full audit trail for messages, members, roles and channels.
- **Temp voice** — join-to-create voice hubs with automatic cleanup.
- **Verification** — a one-click gate that keeps raiders out.
- **Welcomer** — welcome and goodbye cards with per-server messages.

## Dashboard
